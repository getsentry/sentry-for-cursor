# Sentry Cursor Plugin (Deprecated)

> **This repository has been archived.** The Sentry Cursor plugin has moved to [**getsentry/sentry-for-ai**](https://github.com/getsentry/sentry-for-ai), which serves both Cursor and Claude Code from a single repo.

## Migration

Uninstall this plugin and install the new one from the Cursor marketplace (search for "sentry"), or clone the new repo:

```bash
git clone https://github.com/getsentry/sentry-for-ai.git
```

All skills, commands, and MCP configuration are available in the new repo.
